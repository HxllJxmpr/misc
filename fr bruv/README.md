# IA Project - Exploration de l'Intelligence Artificielle

Ce projet propose un site web éducatif et interactif en français, conçu pour démystifier l'intelligence artificielle. Il offre une vue d'ensemble des concepts clés, retrace son histoire, présente ses applications concrètes, aborde les enjeux éthiques cruciaux et fournit des ressources pour approfondir le sujet.

## Structure du Projet

- `assets/` : Contient les ressources visuelles (images, icônes).
- `css/` : Regroupe les feuilles de style (`styles.css`, `responsive.css`, `timeline.css`, `applications.css`, `resources.css`, `ethics.css`, `glossary.css`).
- `js/` : Contient le script JavaScript principal (`main.js`).
- `index.html` : Page d'accueil et introduction.
- `about.html` : Histoire, concepts fondamentaux et figures clés de l'IA.
- `applications.html` : Exemples d'applications de l'IA dans divers secteurs.
- `ethics.html` : Discussion sur les défis et principes éthiques de l'IA.
- `resources.html` : Sélection de cours, lectures et liens utiles.
- `glossary.html` : Définition des termes techniques courants.
- `README.md` : Ce fichier d'information.

## Comment Lancer le Projet

1.  Clonez ce dépôt ou téléchargez l'archive des fichiers.
2.  Assurez-vous que le dossier `assets/images/` contient les images référencées dans le code HTML (ou remplacez-les par les vôtres).
3.  Ouvrez le fichier `index.html` dans votre navigateur web préféré.
4.  Naviguez à travers les différentes pages et sections pour explorer le contenu.

## Fonctionnalités Principales

-   **Contenu Riche et Structuré :** Couverture de multiples facettes de l'IA.
-   **Design Moderne et Responsive :** Adaptation à toutes les tailles d'écrans (mobile, tablette, bureau).
-   **Navigation Intuitive :** Menu clair avec indicateur de page active et menu hamburger sur mobile.
-   **Interactivité :** Animations subtiles au défilement, filtrage dynamique du glossaire, bouton "Remonter en haut".
-   **Thème Sombre :** Option pour basculer entre un thème clair et sombre (préférence sauvegardée).
-   **Accessibilité :** Utilisation de balises sémantiques et d'attributs ARIA pour une meilleure accessibilité.
-   **Code Organisé :** Structure de fichiers claire et code commenté.

## Technologies Utilisées

-   HTML5 (Sémantique)
-   CSS3 (Flexbox, Grid, Variables, Transitions, Animations)
-   JavaScript (ES6+, Manipulation du DOM, Intersection Observer, Event Listeners, LocalStorage)
